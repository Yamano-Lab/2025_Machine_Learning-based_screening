================================================================================
1. プロジェクト概要
================================================================================

【研究目的】
クラミドモナス（Chlamydomonas reinhardtii）の変異株ライブラリーを対象に、
ピレノイド形態を蛍光染色により可視化し、画像ベースの高速スクリーニングを
実施する。異常な表現型を示す株（Hit株）を同定し、遺伝子解析・生理学解析を
通じてピレノイド形成・維持に関わる新規因子を発見する。

【最終目標】
- 数千株規模の変異株スクリーニング
- Hit株の同定と優先順位付け
- 表現型-遺伝子型の相関解析
- 国際学術誌（IF 5-10程度）への論文投稿

【使用技術】
- Python 3.8以上
- TensorFlow/Keras (深層学習)
- StarDist2D (細胞セグメンテーション)
- UMAP (次元削減・可視化)
- scikit-learn (機械学習・統計解析)

================================================================================
2. システム目的
================================================================================

【主要目的】
1. 蛍光顕微鏡画像からの細胞自動検出・抽出
2. ピレノイド形態の定量的評価
3. 野生型からの逸脱度（異常度）の自動判定
4. 表現型の多次元解析とクラスタリング
5. 統計的に有意なHit株の同定
6. 再現性の高い実験結果の生成

【副次目的】
- 人手による評価時間の削減（目標: 95%削減）
- 評価の客観性・定量性の向上
- データの一元管理と追跡可能性の確保
- 将来的な他の表現型解析への拡張性

4.3 表現型定量化機能（新規ファイル: phenotype_quantification.py）
--------------------------------------------------------------------------------

【要件 PH-001】多次元表現型スコアリング
優先度: 最高
内容:
  ピレノイド形態を以下の指標で定量化:
    1. pyrenoid_size: ピレノイド面積（ピクセル数）
    2. pyrenoid_intensity: 蛍光強度平均
    3. pyrenoid_compactness: 円形度（4π面積/周長²）
    4. localization_score: 期待位置（下部中央）からの距離
    5. red_green_ratio: 核/ピレノイド蛍光比
    6. morphology_score: オートエンコーダー再構成誤差（MSE）
    7. overall_phenotype: 統合スコア

実装内容:
  クラス PhenotypicScoring:
    - calculate_phenotype_scores(cell_image, reconstruction_error) → dict
    - batch_score_cells(cell_images, reconstruction_errors) → pd.DataFrame
    - _calculate_compactness(mask) → float
    - _calculate_localization_error(mask) → float
    - _integrate_scores(...) → float

技術詳細:
  - 緑チャネルの75パーセンタイルで閾値処理
  - binary_closing で穴埋め
  - skimage.measure.regionprops で形状特徴抽出
  - 期待位置: (y=48, x=32) ← 64x64画像の下部中央

【要件 PH-002】バッチ処理機能
優先度: 高
内容:
  - 複数細胞の一括スコアリング
  - DataFrameで結果を返す
  - cell_id列で個別細胞を追跡

4.4 統計解析機能（新規ファイル: statistical_analysis.py）
--------------------------------------------------------------------------------

【要件 ST-001】変異株-野生型比較
優先度: 最高
内容:
  - 各変異株の表現型を野生型と統計検定
  - 使用検定: Mann-Whitney U検定（ノンパラメトリック）
  - 効果量: Cohen's d
  - 多重検定補正: Benjamini-Hochberg FDR法

実装内容:
  クラス StatisticalComparison:
    - compare_mutants_to_wildtype(mutant_data, wildtype_data, phenotype_columns)
      → pd.DataFrame with columns:
        * strain_id
        * phenotype
        * p_value
        * p_adjusted (FDR補正後)
        * effect_size (Cohen's d)
        * wt_mean, wt_std
        * mutant_mean, mutant_std
        * n_wt, n_mutant
        * fold_change
        * is_significant (p_adjusted < 0.05)

【要件 ST-002】Hit株の同定
優先度: 最高
内容:
  - 有意な表現型変化を示す株を抽出
  - デフォルト基準:
    * p_adjusted < 0.05
    * |Cohen's d| > 0.8 (中程度以上の効果量)

実装内容:
  - identify_hit_strains(comparison_results, effect_size_threshold, p_threshold)
    → pd.DataFrame:
      * strain_id
      * affected_phenotypes (カンマ区切り)
      * avg_effect_size
      * min_p_adjusted

【要件 ST-003】分類精度の検証
優先度: 中
内容:
  - 自動分類と人手評価の一致率検証
  - 出力指標:
    * Confusion matrix
    * Cohen's Kappa
    * Precision, Recall, F1-score

実装内容:
  - validate_classification_accuracy(automated_labels, manual_labels)
    → dict with sklearn.metrics結果

    2. 返り値コードをチェック
    3. train_aligned_cae.py を実行

優先度: 低
内容:
  - 中断時に再開可能な仕組み

8. 論文化要件
================================================================================

【論文投稿に必要な最小限の追加実験・解析】

【Phase A: データ品質保証（1-2週間）】
- 野生型50-100サンプルで人手評価を実施
- 自動分類精度の検証（目標: Cohen's Kappa > 0.8）

【Phase B: Hit株の生物学的検証（1-2ヶ月）】
- Top 10-20 Hit株の選定（統計的有意性に基づく）
- 生理学的測定:
  * CO2固定速度
  * 光合成効率（Fv/Fm等）
  * 成長速度
- 画像表現型と生理データの相関解析
- 代表株の電子顕微鏡観察（オプション）

【Phase C: 遺伝子解析（2-3ヶ月）】
- 変異株の原因遺伝子同定
  * 既知変異株: アノテーション確認
  * ランダム変異株: マッピング/シーケンシング
- GOエンリッチメント解析
- パスウェイ解析（KEGG等）

9. 付録: 技術仕様詳細
================================================================================

【A. データ形式仕様】

入力画像:
  - ファイル形式: TIFF (multi-channel)
  - サイズ: 2048x2048 pixels (typical)
  - チャンネル:
    * Ch0 (Red): 核染色（Hoechst等）
    * Ch1 (Green): ピレノイド染色（カスタムプローブ）
    * Ch2 (オプション): セグメンテーション用（明視野等）
  - ビット深度: 16-bit
  - ピクセルサイズ: 0.065 µm/pixel (63x対物レンズ)

出力画像（アライメント済み細胞）:
  - ファイル形式: TIFF (float32)
  - サイズ: 64x64 pixels
  - チャンネル: 2 (Red, Green)
  - 値範囲: [0, 1] (正規化済み)

【B. フィルタリングパラメータ推奨値】

形状フィルタ:
  - area: 200 - 8000 pixels
  - solidity: > 0.9 (デフォルト) / > 0.8 (緩和時)
  - circularity: > 0.8 (デフォルト) / > 0.7 (緩和時)
  - eccentricity: < 0.95 (デフォルト) / < 0.98 (緩和時)

境界除外:
  - border_margin: 5 pixels (画像端から)

【C. オートエンコーダーアーキテクチャ】

Encoder:
  Input: (64, 64, 2)
  Conv2D(64) → BN → LeakyReLU → Stride(2,2) → (32, 32, 64)
  Conv2D(128) → BN → LeakyReLU → Stride(2,2) → (16, 16, 128)
  Conv2D(256) → BN → LeakyReLU → Stride(1,1) → (16, 16, 256)

Decoder:
  Input: (16, 16, 256)
  Conv2D(256) → BN → LeakyReLU → (16, 16, 256)
  Conv2D(128) → BN → LeakyReLU → UpSampling(2,2) → (32, 32, 128)
  Conv2D(64) → BN → LeakyReLU → UpSampling(2,2) → (64, 64, 64)
  Conv2D(2, activation='sigmoid') → (64, 64, 2)

損失関数:
  Hybrid Loss = MSE_red + 20.0 * MSE_green + 2.0 * (1 - SSIM)

訓練設定:
  - optimizer: Adam (lr=0.0001)
  - batch_size: 32
  - epochs: 300 (early stopping patience=20)
  - validation_split: 0.2

【D. UMAP設定】

推奨パラメータ:
  - n_neighbors: 15
  - min_dist: 0.1
  - metric: 'euclidean'
  - n_components: 2
  - random_state: 42

入力データ:
  - Encoder特徴量（16x16x256 = 65536次元を flatten）
  - 事前に PCA で 100次元に削減（オプション）

【E. 統計検定設定】

検定手法:
  - 2群比較: Mann-Whitney U検定（両側）
  - 効果量: Cohen's d
  - 多重検定補正: Benjamini-Hochberg FDR法
  - 有意水準: α = 0.05

Hit株判定基準:
  - p_adjusted < 0.05 AND
  - |Cohen's d| > 0.8 (中程度以上の効果)

【F. ファイル命名規則】

細胞画像:
  {original_filename}_cell_{index:04d}.tif
  例: exp001_pos01_cell_0042.tif

統計結果:

モデルファイル:
